# Handoff notes

One file per role: `role-a.md`, `role-b.md`, `role-c.md`. Create yours with your first entry. Only the role's owner and their AI write to it, so these files never conflict.

Newest entry at the top. Under 15 lines. Write it for someone who has never seen your session.

```
## <day date time>, role <A, B or C>, with <tool>

Done:
Not done:
Broken or risky:
Next:
Files:
Other roles need to know:
Checks:
```

In Claude Code, `/handoff` writes this for you. Read it before it is committed.
